# Disney+ Clone

A responsive, high-fidelity front-end clone of the Disney+ streaming platform interface. Built purely with semantic HTML5, custom CSS layout techniques, and vanilla JavaScript to deliver a smooth and engaging user experience.

## ✨ Key Features
* **Dynamic Image Slider:** An auto-scrolling hero banner showcasing featured titles with seamless transitions.
* **Interactive Brand Cards:** Sleek hover and scaling effects for the core Disney+ brand pillars (Disney, Pixar, Marvel, Star Wars, National Geographic).
* **Responsive Video Row Layouts:** Content categorized into smooth, horizontally scrollable movie arrays using CSS Flexbox/Grid.
* **Fully Responsive Design:** Optimized for a seamless transition across mobile devices, tablets, and large desktop screens.

---

## 🛠️ Tech Stack
* **HTML5:** Modern, semantic document structure.
* **CSS3:** Custom properties (CSS variables), layouts using Flexbox/Grid, and keyframe animations.
* **JavaScript (ES6+):** Lightweight DOM manipulation and logic control for interactive components.
